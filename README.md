# تکه‌چین

بازی جورچین تصویری فارسی با HTML، CSS و JavaScript. تصاویر، بافت‌ها و فونت در فایل مستقل تعبیه شده‌اند و پیشرفت هر پازل در حافظهٔ محلی مرورگر یا WebView ذخیره می‌شود.

## ساختار و اجرای وب

- `puzzle-fantasy-mobile.html` ورودی بازی و نسخهٔ مستقل تست موبایل است. فایل را مستقیماً در مرورگر باز کنید. برای اجرای اختیاری با HTTP، در ریشهٔ پروژه `python3 -m http.server 8000` را اجرا کنید و به `http://localhost:8000/puzzle-fantasy-mobile.html` بروید.
- فایل HTML صفحهٔ شروع، خانه، دسته‌بندی‌ها، انتخاب تصویر، بازی، پنجره‌های پیش‌نمایش و مکث و صفحهٔ نتیجه را در خود دارد. نمایش صفحه‌ها با DOM مدیریت می‌شود و کشیدن قطعات با Pointer Events و `touch-action` پیاده شده است.
- فایل ورودی حدود ۲ مگابایت است و ۱۷ تصویر JPEG، یک WebP و یک فونت WOFF2 تعبیه‌شده دارد. فایل‌های CDN یا درخواست اینترنتی زمان اجرا در منبع مشاهده نشد.
- `scripts/build-web.mjs` نسخه‌ای بایت‌به‌بایت از فایل را در `www/index.html` تولید می‌کند. `capacitor.config.json` این پوشه را به پروژهٔ `android/` متصل می‌کند. فایل‌های تولیدشده در Git ثبت نمی‌شوند.

## ساخت آزمایشی اندروید

پیش‌نیازها شامل Node.js مطابق `.nvmrc`، JDK 21، Android SDK Platform 36 و Build Tools 35.0.0 هستند. مسیر SDK را در `ANDROID_HOME` تعیین کنید و مجوزهای SDK را بپذیرید. نسخه‌های Capacitor در lockfile ثبت شده‌اند و Gradle Wrapper نسخهٔ 8.14.3 با چک‌سام و AGP 8.13.0 را به کار می‌گیرد.

```sh
npm ci
npm run android:debug
```

دستور دوم خروجی وب را می‌سازد، Capacitor را همگام می‌کند و `assembleDebug` را اجرا می‌کند. مسیر خروجی `android/app/build/outputs/apk/debug/app-debug.apk` است. `npm run build:web` برای ساخت وب و `npm run android:sync` برای ساخت وب و همگام‌سازی جداگانه در دسترس هستند.

شناسهٔ نهایی تأییدشده `ir.bbehrouz.tikechin`، نام نمایشی «تکه‌چین»، حداقل SDK 24 و نسخهٔ نخست `1.0` با `versionCode=1` تنظیم شده‌اند. فعالیت جهت عمودی را درخواست می‌کند. Capacitor و CSS بازی محدودهٔ امن سیستم را مدیریت می‌کنند و نوارهای سیستم برای پیمایش در دسترس‌اند. بازگشت اندروید پنجرهٔ باز را می‌بندد یا از کنترل بازگشت صفحهٔ فعلی استفاده می‌کند. روی صفحهٔ اصلی، رفتار پیش‌فرض اندروید اعمال می‌شود. برنامه وابستگی شبکه‌ای زمان اجرا ندارد و مجوز اینترنت درخواست نمی‌کند.

## دریافت APK از GitHub

گردش‌کار **Android Debug APK** با پوش به `main`، Pull Request به `main` و اجرای دستی از تب **Actions** اجرا می‌شود. برای اجرای دستی، پس از قرار گرفتن گردش‌کار در شاخهٔ پیش‌فرض، **Run workflow** را بزنید. صفحهٔ اجرای موفق را باز کنید و در بخش **Artifacts** فایل **puzzle-debug-apk** را دانلود و از ZIP خارج کنید. GitHub خروجی را ۱۴ روز نگه می‌دارد. گزارش خطای ساخت در همان صفحه و در گام Gradle در دسترس است.

## محدودیت‌ها و اقدامات انتشار

برای ساخت APK انتشار امضاشده با گردش‌کار دستی **Android Release APK**، راهنمای [امضای انتشار و تنظیم Secrets](docs/android-release.md) را بخوانید. کلید تحت کنترل مالک می‌ماند و بدون تنظیم کامل امضا، ساخت Release متوقف می‌شود.

- پیشرفت محلی است و با پاک کردن داده‌های برنامه از دست می‌رود. فایل مستقل مرورگر و اپلیکیشن فضای ذخیرهٔ جداگانه دارند. روی دستگاه واقعی، حالت پرواز، کشیدن قطعات، بازگشت، بازیابی پیشرفت و نمایشگرهای دارای بریدگی را ارزیابی کنید. برای دستگاه‌های نمایشگر بزرگ، رفتار چرخش را هم بررسی کنید.
- نام و شناسهٔ نهایی با تأیید مالک انتخاب شده‌اند. برای نسخه بعدی، همان شناسه و همان کلید امضا را حفظ کنید. `versionCode` برای هر بار بارگذاری بعدی در Play افزایش می‌یابد و `versionName` نسخهٔ نمایشی است.
- برای AAB ابتدا وب را همگام کنید و پس از تنظیم امن امضای انتشار در Gradle، `./gradlew bundleRelease` را از `android/` اجرا کنید. بسته را با کلید بارگذاری امضا کنید و از Play App Signing برای نگهداری کلید امضای برنامه استفاده کنید. کلید، گذرواژه و فایل تنظیمات امضا را بیرون از Git و در فضای امن نگه دارید.
- مستند فعلی Google Play برای اپ‌ها و به‌روزرسانی‌های جدید Android 16 / API 36 را اعلام کرده است. الزامات را هنگام ارسال دوباره بررسی کنید. [الزامات نسخهٔ هدف](https://developer.android.com/google/play/requirements/target-sdk)
- مالکیت یا مجوز تصاویر و بافت‌ها را ثبت کنید. اعلان مجوز SIL OFL فونت در HTML آمده است. پیش از ارسال، سیاست حریم خصوصی را تهیه کنید و فرم Data safety را بر اساس رفتار واقعی برنامه و SDKها تکمیل کنید. شرایط تست بسته برای نوع و تاریخ ایجاد حساب توسعه‌دهنده را در Play Console بررسی کنید. [راهنمای تست حساب‌های شخصی](https://support.google.com/googleplay/android-developer/answer/14151465)
